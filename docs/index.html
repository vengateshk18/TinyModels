FAQ

Good questions,
straight answers.

Everything you need to know before running a model on your phone. Still curious? The source code is open.

Ask on GitHub

Does TinyModels need an internet connection?

Only for downloading models and for optional web search. Once a model is on your phone, chat, vision, and benchmarks work fully offline — airplane mode is fine.

Which models can I run today?

TinyModels currently runs LiteRT-LM .litertlm models from the Hugging Face catalog. GGUF support is in development and is not available in the current release.

Is my data really private?

Chats, photos, settings, and model files stay in the app's private storage. There are no accounts, analytics, or advertising SDKs. Web search is opt-in and off by default, and model downloads contact Hugging Face only when you start them.

What phone do I need?

Android 8.0 or newer on an arm64 device with at least 4 GB of RAM. For 3B models, 8 GB or more is recommended. The app's device insights screen shows what your phone can comfortably run.

Is TinyModels free?

Yes. TinyModels is free to download and open source under the MIT License. You can inspect the code, build it yourself, or contribute on GitHub.

How do I report a bug or request a feature?

Open an issue on GitHub. For security vulnerabilities, please use the contact on the Security page instead of a public issue.
