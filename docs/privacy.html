Privacy Policy

Effective: 14 October 2026 · App: TinyModels (Android)

TinyModels runs open AI models entirely on your device. This policy describes what the app stores, what leaves your device, and when.

1. Data that never leaves your device

  • Chats and messages — stored only in the app's private on-device database. They are never uploaded anywhere.
  • Photos you attach — processed on-device by the loaded model. They are never uploaded by the app.
  • Downloaded and imported model files — kept in the app's private storage. Exporting a file only happens when you explicitly choose a destination folder.
  • Settings — theme, inference, and download preferences stay on-device.

2. Data that leaves your device (only when you ask)

  • Model downloads. When you download a model, the app connects to Hugging Face (huggingface.co) to fetch model files. Standard connection metadata (e.g. IP address) is visible to Hugging Face as with any download. If you access a gated model, the access token you saved in Settings is sent to Hugging Face to authorize the download — and only then.
  • Web search (opt-in). Web search is off by default. If you enable it globally in Settings and per chat, the model may issue web searches when it needs current information. Search queries are sent to public search endpoints (DuckDuckGo, Bing, Wikipedia) and therefore leave your device.
  • Downloadable fonts (opt-in). If you pick a non-system font in Settings, the font files are fetched from Google Fonts. Using the default system font makes no such connection.

3. What we collect

Nothing. The app has no user accounts and ships with no analytics, advertising, or crash-reporting SDKs. The developer receives no data from the app — the only information ever shared is what you choose to send (e.g. a bug-report email or a model download request to Hugging Face).

4. Permissions and why

  • INTERNET — model downloads, optional web search, optional fonts.
  • ACCESS_NETWORK_STATE — detecting offline state and unmetered (Wi-Fi) connections for the Wi-Fi-only download setting.
  • FOREGROUND_SERVICE / FOREGROUND_SERVICE_DATA_SYNC — keeping model downloads running reliably in the background.
  • POST_NOTIFICATIONS — download progress notifications (with a Cancel action). You can deny this; downloads still work.

Import/export of model files uses the system file picker (Storage Access Framework), so no broad storage permission is requested.

5. Device backups

Android backup is enabled, so app data (chats, settings) may be included in your own device/cloud backups under your Google account, governed by Google's terms — the developer has no access to those backups.

6. Children

The app collects no data from anyone, including children. Model files are large technical artifacts; there is no user-generated content shared with anyone.

7. Changes to this policy

Material changes will be published on this page with a new effective date. Continued use of the app after a change means you accept the updated policy.
