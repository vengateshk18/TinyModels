Security practices

Effective: 14 October 2026 · App: TinyModels (Android)

1. On-device by design

Inference runs locally with an on-device runtime. There is no app server, no user database on our side, and therefore no server-side breach surface for your chats.

2. Access tokens

  • Your optional Hugging Face token is stored only in the app's private on-device preferences.
  • It is transmitted solely to huggingface.co over HTTPS when downloading a gated model, and never logged, cached elsewhere, or shared.
  • You can view, replace, or remove it at any time in Settings → Hugging Face.

3. Files and storage

  • Model files live in the app's private internal storage, inaccessible to other apps.
  • Import/export goes through Android's Storage Access Framework (system picker): the app receives access only to the specific file or folder you choose — it does not request broad external-storage permission (MANAGE_EXTERNAL_STORAGE is not used).
  • Deleting a model in the app deletes its files from the device.

4. Network hygiene

  • All network traffic uses HTTPS endpoints.
  • No third-party analytics, advertising, or crash-reporting SDKs are bundled, so there are no hidden data recipients.
  • Web search is strictly opt-in (global switch plus per-chat toggle).

5. Transparency

The app is open source at github.com/vengateshk18/TinyModels. Every claim on this page can be checked against the code.

6. Reporting a vulnerability

If you find a security issue, please email vengatesh00014@gamil.com with details and steps to reproduce. Please avoid opening public issues for vulnerabilities until a fix is available.
